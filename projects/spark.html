Spark Networks

Spark Networks is a global dating company that operates several premium online platforms, including Zoosk and EliteSingles. We were tasked with creating a white-label brand to unify and scale their product branding across multiple platforms.

  • Componentizing designs
  • Design tokens
  • Component Accessibility
  • Style Dictionary
  • Documentation

When I joined the project...

...the UI team was working under tight deadlines, prioritizing speed over structure. Without time to properly set up components and tokens, engineers followed suit, leading to inconsistencies between the design files and developed screens. A basic token structure was in place, but it lacked support for a proper white-label customization.

The solution

  • A flexible, multi-platform design system called Flint
  • Full support for white-labeling.
  • A simplified variable and token structure, 32% smaller.
  • Automatic Figma to code token updates using Tokens Studio and Style Dictionary.

Planning

A wizard once told me:

Doing work on a design system while others design is like fixing the plumbing in a house while your roommates are taking showers. — ChatGPT, 2025

You're making essential changes to a shared system, but if you're not careful, you risk interrupting everyone mid-shower, causing frustration. Coordination, timing, and communication are key to avoid chaos.

With that in mind, before getting my hands dirty, and extensive audit was conducted to check three main things:

  • What design elements were “component” worthy
  • What was the status of these components (do they already use variables? are they accessible? are they named properly? are they properly documented?)
  • Which components affect which (how big will my impact be if I change the icons component, for example? What about buttons?)

After the audit was complete, we had a better overview of how much work we'd have ahead, and the current status of Flint.

White labeling

After laying the groundwork for the design tokens, it was time to tackle the white-labeling of Spark's app.

The result was a 3-level token structure. Simple, but effective and highly reusable.

Together with the design team, we decided which of the elements needed to be branded, and developed a structure that Spark could apply to countless brands.

Token sync

Added to the Figma variables, we created a fully automated process where tokens would be exported from Figma using Tokens Studio, and updated in iOS, Android and web with Style Dictionary.
